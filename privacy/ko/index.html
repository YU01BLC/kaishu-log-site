1. 운영자

Kaishu Log는 투입액과 회수액을 기록하고 집계하는 앱이며 Kaishu Log 운영팀이 운영합니다.

2. 데이터, 계정 및 동기화

앱은 투입액, 회수액, 수지, 메모, 사용자가 만든 라벨, 날짜 및 테마 설정을 기기 안에서 처리합니다. 사용자 등록, 로그인, 클라우드 동기화 또는 기록용 개발자 서버를 제공하지 않습니다. 기록 데이터는 원칙적으로 기기 내 SQLite 데이터베이스에 저장됩니다.

분석 잠금 해제 상태는 현재 앱 프로세스 세션 동안 메모리에만 유지되며 SQLite나 다른 영구 저장소에 저장되지 않습니다. 앱을 백그라운드로 보낸 경우에는 같은 프로세스가 계속되는 동안 잠금 해제 상태가 유지되지만, 앱 프로세스를 완전히 종료하면 분석이 다시 잠깁니다.

3. 광고, 동의 관리 및 제3자 처리

앱은 Google Mobile Ads SDK를 사용하며 다음 형식의 광고를 요청할 수 있습니다.

  • 배너 광고(Banner): 홈과 보상형 광고의 보상을 획득한 후 잠금 해제된 분석 화면에 배너 광고가 표시될 수 있습니다.
  • 전면 광고(Interstitial): 새 기록 또는 기존 기록의 업데이트가 성공적으로 저장된 후라는 작업 구분 시점에 전면 광고가 표시될 수 있습니다. 저장 전이나 입력 중에는 이 목적으로 광고를 요청하지 않습니다.
  • 보상형 광고(Rewarded): 사용자가 분석을 보기 위해 명시적으로 ‘광고 보기’를 선택한 경우에만 보상형 광고를 요청합니다. 보상 획득이 확인된 경우에만 현재 앱 프로세스 세션 동안 분석 잠금을 해제합니다.

네트워크 연결, 동의 상태, 광고 재고 또는 기타 조건에 따라 광고를 가져오거나 표시하지 못할 수 있으며, 광고 표시를 보장하지 않습니다.

Google User Messaging Platform(UMP)으로 동의 상태를 확인하며 광고를 요청할 수 없는 상태에서는 요청하지 않습니다. 현재 구현은 비개인 맞춤 광고만 요청합니다. 필요한 경우 설정의 ‘광고 개인정보 설정’에서 동의 및 개인정보 선택 항목을 다시 표시할 수 있습니다.

광고 게재, 부정 사용 방지, 성과 측정 및 진단을 위해 Google 등의 광고 서비스 제공자가 IP 주소, 기기 및 OS 정보, 네트워크 정보, 광고 노출·클릭·완료 등의 광고 이벤트, 진단 정보와 동의·개인정보 설정을 처리할 수 있습니다. 자세한 내용은 Google 개인정보처리방침, Google 서비스를 사용하는 사이트 또는 앱의 정보 사용 방식, Google 광고 기술, 광고 설정을 확인하세요.

앱은 투입액, 회수액, 수지, 메모, 사용자가 만든 라벨 또는 백업 JSON을 광고 사업자에게 자체 전송하지 않습니다. 이번 production release는 iOS / App Store 버전만 대상이며 Android AD_ID는 이번 production release 범위에 포함되지 않습니다. iOS 버전은 ATT 권한을 요청하지 않고 앱 자체에서 IDFA를 사용하지 않으며, 정확한 위치, 연락처, 사진, 카메라 또는 마이크도 사용하지 않습니다.

4. 백업 및 복원

사용자가 직접 조작한 경우에만 기록과 복원 대상 설정을 JSON 백업 파일로 외부에 공유하거나 저장할 수 있습니다. 백업 JSON은 암호화되지 않습니다. 복원하면 기기 내 현재 기록, 라벨 및 복원 대상 설정이 덮어쓰입니다. 외부에 저장하거나 공유한 파일은 모든 데이터 삭제나 앱 제거로 삭제되지 않으며 앱에서 삭제할 수 없습니다.

5. 저장 및 삭제

기기 내 데이터는 사용자가 앱에서 모든 데이터 삭제를 실행하거나 앱을 삭제할 때까지 보관됩니다. 앱 삭제 후 기기 내 데이터 처리는 운영체제 및 기기 사양을 따릅니다.

6. 공개 페이지와 GitHub

이 공개 페이지는 GitHub Pages에서 호스팅됩니다. GitHub는 보안을 위해 IP 주소 등을 처리할 수 있습니다. GitHub의 처리에는 GitHub 일반 개인정보 보호정책이 적용됩니다.

7. 변경 및 문의

이 방침을 변경하는 경우 이 페이지의 최종 업데이트 날짜를 변경하여 공개합니다. kaishulog.support@gmail.com으로 문의하거나 지원 및 사용 방법을 확인하세요.
