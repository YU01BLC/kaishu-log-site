1. Operator

Kaishu Log records and summarizes amounts spent and returned. It is operated by Kaishu Log Support.

2. Data, Accounts, and Sync

The app handles amounts spent and returned, results, notes, user-created labels, dates, and theme settings on your device. It does not provide user accounts, login, cloud sync, or a developer server for recording data. Entries are generally stored in an on-device SQLite database.

Analysis unlock state is held only in memory during the current app process session and is not saved to SQLite or other persistent storage. Sending the app to the background alone preserves the unlock while the same process continues, but fully terminating the app process locks Analysis again.

3. Ads, Consent, and Third-Party Processing

Kaishu Log uses the Google Mobile Ads SDK and may request the following ad formats:

  • Banner: Banner ads may appear on Home and on Analysis after it has been unlocked by earning the rewarded-ad reward.
  • Interstitial: An interstitial may appear at the logical break after a new entry or an update is saved successfully. It is not requested for this purpose before saving or while you are entering data.
  • Rewarded: A rewarded ad is requested only when you explicitly choose “Watch Ad” to view Analysis. Only an earned reward unlocks Analysis for the current app process session.

An ad may not be obtained or shown because of network connectivity, consent status, ad inventory, or other conditions. Ad display is not guaranteed.

Google’s User Messaging Platform (UMP) checks consent status, and the app does not request an ad when ads cannot be requested. The current implementation requests non-personalized ads only. When required, you can reopen consent and privacy choices from “Ad Privacy Options” in Settings.

For ad delivery, fraud prevention, measurement, and diagnostics, Google and other ad service providers may process IP addresses, device and OS information, network information, ad events such as impressions, clicks, and completions, diagnostic information, and consent or privacy settings. See Google’s Privacy Policy, How Google uses information from sites or apps that use its services, Google’s advertising technologies, and Ad Settings.

Kaishu Log does not independently send amounts spent or returned, results, notes, user-created labels, or backup JSON to ad providers. This production release is for iOS / the App Store only, and Android AD_ID is outside this production release’s scope. The iOS app does not request ATT permission, and the app itself does not use IDFA. It also does not use precise location, contacts, photos, camera, or microphone.

4. Backup and Restore

Only when you take an explicit action can entries and restorable settings be shared or saved externally as a JSON backup. Backup JSON is not encrypted. Restoring it overwrites current entries, labels, and restorable settings on the device. Files saved or shared elsewhere are not removed by Delete All Data or uninstalling the app and cannot be deleted from this app.

5. Storage and Deletion

On-device data is retained until you use Delete All Data in the app or uninstall the app. Data handling after uninstall follows the operating system and device specifications.

6. Public Pages and GitHub

These public pages are hosted with GitHub Pages. GitHub may process IP addresses and related information for security. GitHub’s processing is governed by the GitHub General Privacy Statement.

7. Changes and Contact

If this policy changes, we will publish the change by updating the last-updated date on this page. Contact kaishulog.support@gmail.com or visit Support and Usage.
