1. 營運方

Kaishu Log用於記錄與彙總投入及回收金額，由Kaishu Log營運團隊營運。

2. 資料、帳戶與同步

本App在裝置內處理投入金額、回收金額、收支、備註、使用者建立的標籤、日期與主題設定。不提供使用者註冊、登入、雲端同步或用於記錄資料的開發者伺服器。記錄資料原則上儲存在裝置內的SQLite資料庫。

分析解鎖狀態僅在目前App處理程序工作階段期間保存在記憶體中，不會寫入SQLite或其他永久儲存空間。僅將App移至背景時，只要相同處理程序仍持續執行，解鎖狀態就會保留；完全結束App處理程序後，分析將再次鎖定。

3. 廣告、同意管理與第三方處理

本App使用Google Mobile Ads SDK，並可能請求下列形式的廣告：

  • 橫幅廣告（Banner）：首頁以及透過獎勵廣告取得獎勵後解鎖的分析頁面可能顯示橫幅廣告。
  • 插頁式廣告（Interstitial）：新增記錄或更新記錄成功儲存後，可能在此操作節點顯示插頁式廣告。儲存前或輸入期間，不會為此目的請求該廣告。
  • 獎勵廣告（Rewarded）：僅在使用者為了查看分析而明確選擇「觀看廣告」時請求獎勵廣告。僅在確認取得獎勵時，才會在目前App處理程序工作階段期間解鎖分析。

由於網路連線、同意狀態、廣告庫存或其他條件，廣告可能無法取得或顯示。本App不保證廣告一定會顯示。

App透過Google User Messaging Platform（UMP）確認同意狀態，無法請求廣告時不會送出廣告請求。目前的實作僅請求非個人化廣告。需要時，可從設定中的「廣告隱私設定」重新顯示同意與隱私選項。

為了廣告投放、防止詐欺、成效衡量與診斷，Google等廣告服務商可能處理IP位址、裝置與作業系統資訊、網路資訊、廣告曝光、點擊、完成等廣告事件、診斷資訊以及同意與隱私設定。詳情請參閱Google隱私權政策、Google如何使用來自採用其服務的網站或App的資訊、Google廣告技術與廣告設定。

本App不會自行將投入金額、回收金額、收支、備註、使用者建立的標籤或備份JSON傳送給廣告服務商。本次production release僅適用於iOS / App Store版本，Android AD_ID不在本次production release範圍內。iOS版本不會要求ATT權限，App本身不使用IDFA，也不使用精確位置、聯絡人、照片、相機或麥克風。

4. 備份與還原

僅在使用者主動操作時，記錄與可還原設定才能以JSON備份檔案分享或儲存至外部。備份JSON未經加密。還原會覆寫裝置內目前的記錄、標籤與可還原設定。儲存在外部或已分享的檔案不會因「刪除所有資料」或解除安裝App而刪除，也無法從本App中刪除。

5. 儲存與刪除

裝置內資料會保留到使用者在App內執行「刪除所有資料」或解除安裝App為止。解除安裝App後的裝置內資料處理依作業系統與裝置規則。

6. 公開網頁與GitHub

本公開網頁託管於GitHub Pages。GitHub可能基於安全目的處理IP位址等資訊。GitHub的處理適用GitHub一般隱私權聲明。

7. 修訂與聯絡

修訂本政策時，將更新本頁面的最後更新日期並予以公布。請寄信至kaishulog.support@gmail.com，或前往支援與使用說明。
